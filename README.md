# EAMDR Framework

Reference implementation accompanying the manuscript:

**From Hand Posture to Motor Intent:  
A Dual-Boundary Hybrid Control Framework for Accessible Human–Computer Interaction**

## Overview

This repository contains the reference implementation of the **Equilibrium-Anchored Motor Deviation Representation (EAMDR)** framework as evaluated in the **RehabReach** rehabilitation platform.

The repository is intended to support reproducibility of the computational and engineering validation reported in the paper.

## Repository contents

- `reference_impl/` – Core implementation of the EAMDR framework
- `sample_logs/` – Representative execution logs used for analysis
- `examples/` – Example datasets and validation sessions
- `figures/` – Figures generated from the experimental logs
- `docs/` – Supplementary documentation

## Scope

This repository contains only the components required to reproduce the framework and experimental results described in the manuscript.

The complete RehabReach application is **not** included.
